# AI Developer — портфолио

Одностраничный сайт-портфолио начинающего AI-разработчика. Сайт представляет услуги по разработке сайтов, Telegram-ботов, AI-автоматизаций и небольших веб-приложений, а также содержит демонстрационные проекты.

## Возможности

- адаптивный тёмный интерфейс для смартфонов и компьютеров;
- Hero-блок с основными направлениями работы;
- разделы «Обо мне», «Услуги», «Проекты», «Технологии» и «Этапы работы»;
- три учебных или концептуальных проекта с описанием стека;
- якорная навигация и плавная прокрутка;
- адаптивная контактная форма с базовой клиентской валидацией;
- доступные labels, focus-состояния и семантическая HTML-разметка.

## Технологии

- Next.js 16 и App Router;
- React 19;
- TypeScript;
- Tailwind CSS 4;
- ESLint.

## Локальный запуск

Установите зависимости:

```bash
npm install
```

Запустите dev-сервер:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Production-сборка и запуск:

```bash
npm run build
npm run start
```

Проверка кода:

```bash
npm run lint
```

## Статус проекта

Учебный сайт-портфолио.

Проекты на странице являются учебными или концептуальными примерами. Сайт не заявляет о реальных клиентах, отзывах, коммерческом опыте или достижениях.

## Контактная форма

Форма находится в демонстрационном режиме. Она проверяет заполнение полей и показывает сообщение об успешной отправке только в интерфейсе. Данные не сохраняются в базе данных и не отправляются на внешний сервер.
